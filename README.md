# ⚙️ IronPulse - Server Side

This is the back-end API server for **IronPulse**, built using Node.js, Express.js, and MongoDB.

## 🚀 API Base URL
- **Live Server API:** https://b13-a10-frontend.vercel.app/

## ✨ Key Features & API Endpoints
- **Authentication Routes:** User creation, JWT authentication, and authorization middleware.
- **Trainer & Class Management:** CRUD operations for classes, trainers, and bookings.
- **Database Integration:** MongoDB for persistent and secure data storage.
- **Secure Operations:** Environment variable protection for sensitive database credentials.

## 🛠️ Technologies Used
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **Security & Utilities:** CORS, Dotenv, JSON Web Token (JWT)
